# Contributing to DevLinks

Thanks for helping out! Keep contributions small and friendly.

## Workflow
1. Find an issue labelled `good first issue`. Check it isn't assigned or already linked to a PR.
2. Comment to claim it.
3. Fork the repo and clone your fork.
4. Create a branch — never work on `main`:
   ```
   fix/<issue-number>-short-description
   ```
5. Make ONE scoped change. One issue = one pull request.
6. Commit using Conventional Commits:
   ```
   fix: correct typo in main heading
   ```
7. Open a pull request, fill the template, and link the issue with `Fixes #<number>`.
8. Our review bot will comment on your PR. In this training repo it always requests changes — reply politely and keep going.
